## Overview

SecureFlow Scanner is a lightweight, opinionated security tool designed to run inside GitHub Actions workflows. It combines Static Application Security Testing (SAST) with Software Composition Analysis (SCA) to catch vulnerabilities before they reach production.

## Features

- **Dependency Auditing** — Scans `package.json`, `requirements.txt`, `go.mod`, and more
- **Code Pattern Detection** — Identifies common security anti-patterns (hardcoded secrets, SQL injection vectors, etc.)
- **GitHub Actions Native** — Runs as a composite action with minimal config
- **PR Comments** — Automatically posts findings as pull request comments with severity ratings

## Architecture

```
secureflow-scanner/
├── action.yml          # GitHub Action definition
├── scanners/
│   ├── sast.py         # Static analysis engine
│   └── sca.py          # Dependency scanner
├── reporters/
│   └── github.py       # PR comment reporter
└── Dockerfile          # Container for consistent execution
```
