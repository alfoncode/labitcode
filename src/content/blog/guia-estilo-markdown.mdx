Este artículo sirve como una **guía de estilo interactiva** para todos los elementos Markdown y MDX soportados por labitcode. Utilízalo como referencia para comprobar cómo se visualizará tu contenido una vez publicado.

---

## Encabezados

Los encabezados definen la jerarquía estructural de tu contenido. Admitimos niveles 2–4 dentro de los artículos (h1 se reserva exclusivamente para el título principal).

### Encabezado de Tercer Nivel

Utiliza h3 para subsecciones dentro de una temática principal.

#### Encabezado de Cuarto Nivel

Emplea h4 con moderación, para desgloses muy específicos.

## Estilos de Texto en Línea

El texto de párrafo estándar se presenta en un tamaño de lectura cómodo con un interlineado generoso que favorece la legibilidad:

- **Texto en negrita** utiliza `**doble asterisco**`
- _Texto en cursiva_ utiliza `*un solo asterisco*`
- **_Negrita y cursiva_** utiliza `***tres asteriscos***`
- ~~Tachado~~ utiliza `~~doble virgulilla~~`
- `código` en línea utiliza comillas invertidas y se renderiza en tipografía monoespaciada con fondo sutil

Este es un párrafo con un [enlace a nuestra página principal](https://labitcode.com/es) para comprobar el estilo de los enlaces. Cuentan con un color de acento y subrayado desfasado para optimizar la lectura.

## Bloques de Código

Los bloques de código son uno de los componentes esenciales en un blog de ingeniería. Así lucen en diferentes lenguajes:

### TypeScript

```typescript
interface BlogPost {
  title: string;
  description: string;
  pubDate: Date;
  tags: string[];
  author: "Alfonso Garcia" | "AI";
  draft?: boolean;
}

async function getPublishedPosts(): Promise<BlogPost[]> {
  const allPosts = await getCollection("blog");
  return allPosts
    .filter((post) => !post.data.draft)
    .sort((a, b) => b.data.pubDate.valueOf() - a.data.pubDate.valueOf());
}
```

### Python

```python
from dataclasses import dataclass
from datetime import datetime
from typing import Optional

@dataclass
class Project:
    """Representa un proyecto en el laboratorio."""
    name: str
    stack: list[str]
    status: str = "active"
    created_at: datetime = datetime.now()
    repo_url: Optional[str] = None

    def is_active(self) -> bool:
        return self.status == "active"

    def __repr__(self) -> str:
        return f"<Project: {self.name} [{self.status}]>"

# Uso
scanner = Project(
    name="SecureFlow",
    stack=["Python", "Docker", "Redis"],
    repo_url="https://github.com/alfoncode/labitcode/secureflow"
)
print(scanner)  # <Project: SecureFlow [active]>
```

## Flujo Mixto de Contenido

Así interactúan de forma natural los distintos componentes dentro de un artículo real:

La premisa clave tras nuestra arquitectura radica en que **las webs de contenido no necesitan un entorno de ejecución de JavaScript**. Al examinar qué hace un blog, el proceso es simple:

1. Renderizar Markdown a HTML
2. Aplicar estilos visuales coherentes
3. Generar etiquetas meta y Open Graph para SEO

Eso es todo. El resto —gestión de estado global, hidratación, conciliación del DOM virtual— constituye _sobrecarga_ innecesaria en este escenario. Así lo plasmamos en código:

```typescript
// Esto es todo lo necesario. Sin artificios.
const posts = await getCollection("blog");
const sorted = posts
  .filter((p) => !p.data.draft)
  .sort((a, b) => b.data.pubDate.valueOf() - a.data.pubDate.valueOf());
```

> El código más rápido es el que jamás se envía al navegador del usuario.

¿El desenlace? **Puntuaciones de 100/100 en Lighthouse** en todas las categorías, con un `Time to Interactive` medido en milisegundos, no en segundos.

## Resumen

Esta guía de estilo engloba los componentes Markdown esenciales para labitcode:

- **Estilos en línea**: negrita, cursiva, tachado, código y enlaces
- **Elementos de bloque**: encabezados, párrafos, citas y separadores
- **Bloques de código**: resaltado multilingüe con Shiki
- **Listas**: ordenadas, desordenadas, anidadas y tareas interactivas
- **Tablas**: alineación y contraste cuidado
- **Imágenes**: bordes redondeados y centrado uniforme

Cada elemento está calibrado para garantizar la máxima legibilidad tanto en modo **claro** como **oscuro**.
